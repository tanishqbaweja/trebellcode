# Trebell Code 2.0.1

Version 2.0.1 is a small update to 2.0.0. Trebell Native in the app and the Native that Trebell's benchmarks run now read one shared configuration, so the Native you download is the Native the benchmarks run. The window also loads less before its first screen.

## Trebell Native

- **One configuration for the app and the benchmarks.** Native's settings in the app and in Trebell's benchmark runs now come from one place, and a test keeps the two from drifting apart.
- **No extra check before an answer.** Native no longer makes a separate request to judge a code change before it answers. On OpenAI, replies on turns that change code now stream in as they are written too.
- **More room in one message.** A message can run up to 500 model turns and 5,000 tool calls, instead of stopping at 24 and 100. Stop and a goal's budgets still end the work when you want.
- **gpt-6-luna on OpenAI.** If you have not picked a model, Native uses gpt-6-luna when your OpenAI model list has it. On gpt-6-luna, Native thinks at Max unless you choose another level, and the Thinking picker shows Max instead of a Default option; other models keep Default. gpt-6-luna gets a 272K-token context window, with OpenAI's own compaction at 245K.
- **Tools.** Background process tools are in every Native thread, not only when a message mentions them. Source control tools come when a message asks for Git work, such as "commit this", "push it", "open a PR" or "revert the last commit", instead of whenever a Git word appears; the same rule picks the tools of a Codex thread's first message. Native's instructions no longer say that web research is available, since Native has no web search tool.
- **Context meter.** The context meter, automatic compaction and the next message's budget now read the size of the turn's last request instead of adding up every request in the turn: a turn of six 45K requests now reads 45K, not 270K. A compaction's summary runs at the provider's own thinking level, so a thread at Max still gets one.

## Interface

- The Runtime tab, History's list, the message search in threads and the command palette's commands load right after the window first draws, or as soon as you open them, so the first screen loads less code. The approval card is still ready at once, and a part that cannot load says so in its place while the rest of the panel keeps working.

## Other

- Trebell Code is free to download and use. The app no longer carries LICENSE and NOTICE files of its own, and the notices of the open source components it includes stay in Settings, Open source licenses.

## Install and update

- Windows x64: download and run `Trebell-Code-Setup-2.0.1.exe` from the releases repository, https://github.com/tanishqbaweja/trebellcode-releases.
- If you have 2.0.0, the in-app updater offers 2.0.1; it downloads and installs only when you choose to.
- The installer is not signed, so Windows SmartScreen may ask you to confirm it before it runs (More info, then Run anyway).

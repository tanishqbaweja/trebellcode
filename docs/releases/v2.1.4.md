# Trebell Code 2.1.4

Version 2.1.4 is an update to 2.1.3. An estimated cost on the Usage page and in the composer charges each cached token once, and Trebell Native's turns can get one from prices you save in Settings. The checks Trebell runs after a turn stop when you do not allow one, say in plain words what they check and take their result from the command they ran, and Trebell Native no longer counts the time you take to approve a command against its time limit. Muse Code's approval card says when a command cannot run because its sandbox is not available, and loading earlier messages in a conversation keeps your place.

## Usage and cost

- **An estimated cost charges each cached token once.** When Trebell works out a turn's cost from prices saved in Settings, on the Usage page and in the composer, it counts each input token once: cache reads and writes at their own prices, or at the input price if you left those empty, the rest of the input at the input price, and output at the output price. It reads each harness's records the way that harness counts: Codex, Trebell Native and Muse Code count cached tokens inside their input, which 2.1.3 then charged a second time, and Claude Code and OpenCode count them apart.
- **The Usage page's Input card counts every input token once**, the cached ones with it, however a harness records them. For Claude Code and OpenCode it left out their cache reads and writes.
- **The Models card names each harness that used a model.** A model two harnesses ran, such as Muse Code and Trebell Native on the same Meta model, has a row for each, with its own turns, tokens and cost, where 2.1.3 put both in one row under one harness's name.
- **Trebell Native's turns can get an estimated cost.** Settings, Agents & models now shows the Custom models card for Trebell Native. Prices you save there for models of Native's provider, in USD per million tokens, give Native's turns on those models an estimated cost on the Usage page and in the composer. Pick a model from the provider's list in Model ID, or add one the list leaves out.
- A listed model that you price in the Custom models card, for any harness, stays one entry in the model picker under the name its list gives it, or the display name you give it, and is no longer labelled custom.
- **Muse Code on an API key has no subscription limits to show.** Its card on the Usage page says "This runtime/account does not expose subscription limits to Trebell.", as Claude Code's does on an API key. 2.1.3 said Muse Code had not reported its subscription windows yet, or showed the windows an earlier signed-in turn had reported.

## Checks after a turn

When a turn changes files, Trebell plans checks of the change, and can start a check turn in the same thread for the next check it needs.

- **A check you do not allow stops the automatic checking.** When you decline a command a check turn asks to run, or leave its approval unanswered until it expires, Trebell starts no more automatic check turns after it. The check's row turns into a warning that ends in not allowed, and the turn's verification row ends in checking stopped.
- **An automatic check turn is not followed by another for the same step.** 2.1.3 could start one after another for a step that a check turn left unchecked, up to five in a row.
- **A check's row says in plain words what it checks**, such as Automatic check · running the tests, or Automatic check · trying the changed behavior, where it read Automatic same-thread check turn with the step's ID. The turn's verification row names the next check the same way, such as next: running the tests.
- **A check of the changed behavior takes its result from the last command the check turn ran.** Such a check has no command of its own, so Trebell tells the check turn that its last command is the check: exit code 0 passes it, and any other exit code fails it and starts a repair. When that last command could not start, was refused or stopped, or never ended, the check has no result, and an earlier command does not stand in for it.
- **A command that ended without an exit code no longer passes a check.** 2.1.3 read a missing exit code as 0, so a command that could not start could count as a check that passed.

## Trebell Native

- **A command's time limit starts when the command starts**, never while you are asked to approve it. In 2.1.3 the wait for your answer counted against the limit, so a command you approved late could be cancelled as timed out. A command nobody is asked about, as in Full access, is timed from its call as before.
- This change is in the code that Trebell's benchmark runs share with the app, so the Native you download is still the Native the benchmarks run. Benchmark runs ask for no approvals, so their commands are timed as before.

## Muse Code

- **The approval card says when a command cannot run.** When Muse Code's host reports that its sandbox is not available, as Muse Code 1.4.13 does on Windows, a command it asks to run fails even if you allow it. The card now says so before you answer: "Muse Code reports that its sandbox is not available, so this command will fail even if you allow it. To let it run commands, switch this task to Full access, which runs them without the sandbox and without asking."
- A command its sandbox kept from starting says so on its row, in place of Muse Code's environment failure message: "Muse Code did not run this command because its sandbox is not available. To let it run commands, switch this task to Full access, which runs them without the sandbox and without asking." A command that ran keeps its own output and exit code, even when its command or output mentions that message.

## Conversations

- **Loading earlier messages keeps your place.** When earlier messages load above what you are reading, the view stays where it was. In 2.1.3 it could jump by the height of a message near the top, or go to the end when the newest messages were a little taller than the view. It also holds while a turn is still running.

## Settings

- The Agent harness card names Grok Build in full: "Codex, Claude Code, OpenCode, Cursor, Grok Build, Antigravity and Muse Code run as their real harnesses."
- Searching Settings for prices or cost finds the Custom models card.

## Install and update

- Windows x64: download and run `Trebell-Code-Setup-2.1.4.exe` from the releases repository, https://github.com/tanishqbaweja/trebellcode-releases.
- If you have 2.0.0, 2.0.1, 2.1.0, 2.1.1, 2.1.2 or 2.1.3, the in-app updater offers 2.1.4; it downloads and installs only when you choose to.
- The installer is not signed, so Windows SmartScreen may ask you to confirm it before it runs (More info, then Run anyway).

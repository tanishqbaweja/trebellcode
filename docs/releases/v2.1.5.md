# Trebell Code 2.1.5

Version 2.1.5 is an update to 2.1.4. Trebell Native reads every document you attach at every access level, and its conversations go on normally after Trebell restarts. A step that was declined or not allowed says so on its row, with why it did not run, and approval cards and errors say in plain words what they mean. Each conversation keeps its own draft and attached files, and a key you type for a relay provider is checked before it is kept.

## Attached files

- **Trebell Native reads the documents you attach.** Native gets the text of every document attached to its thread, and its read and search tools open that thread's attachments where they are, at every access level and without asking. Nothing else outside the project opens that way. It can read any lines of a long document's text, and it finds an attachment by the path it was given or by a path written from the project.
- In Supervised and Auto-accept edits, Native can look again at the stored output of a project or attachment read without asking, since that read already ran. Any other stored output still asks.
- **A file that is no longer on this computer comes off the message.** When you send a message whose attached file is gone, Trebell takes its chip off the draft and says so once in plain words, so the next send goes. The same holds for a follow-up, a steer, an edited follow-up in the queue, a send to several models, a background send and Send now on a follow-up in the queue. A follow-up in Trebell's own queue is held for you with the file taken off, and a gone copy on a remote environment is named with its environment.
- An image that is not a valid PNG or WebP picture is refused with a plain reason, without naming the parts of the file Trebell read.

## When Trebell restarts

- **A conversation goes on after a restart.** Trebell Native sends each tool call once with the output it first settled with, including in a thread that had stored it twice, so a provider no longer refuses the thread after a restart. A tool result that comes late is kept in the turn that holds its call.
- The usage a provider reported for a Native turn that a restart ends is kept.
- A command whose approval card was still waiting when Trebell closed or was stopped shows as not run, saying why.
- A reopened turn shows the time it showed live, the model and mode it ran with over its reply, and the thread's context reading. A turn Trebell starts itself, such as a check, names the harness alone.
- After a restart, a new task opens on the model the composer had.
- Some of these changes are in the code that Trebell's benchmark runs share with the app, so the Native you download is still the Native the benchmarks run. Benchmark runs attach no files and do not restart, so they run as before.

## Steps that did not run

- **A step that was declined or not allowed says so.** Its row says declined or not allowed with why it did not run, and it is no longer counted as failed. This covers Trebell Native's calls, an app's and an MCP server's tools, your own rules (with their reason), Claude Code and OpenCode steps their access level refused before anyone was asked, and steps an ACP harness's access level refused. Claude Code is told the same words, in place of a note about read-only mode.
- The Runtime panel counts a step its access level did not allow among the finished steps.

## Approval cards and errors

- **Trebell Native's approval cards say what they ask**, in plain words: a file write, a command or an MCP tool by its server's own name, with what each access level asks before. A background command's card says that it starts in the background.
- **A provider's refusal of a Native turn reads in plain words** with its reason, instead of its raw response. When a provider has not answered, the turn says it is still waiting for it, also for a request Native sent again after a refusal it could retry.
- Muse Code's read rows name the file and the part they read, and an uploaded file whose name ends in .txt by its own name.

## Providers and harnesses in Settings

- **A key you type for a relay provider is checked with that provider before it is kept.** A key the provider refuses is not kept, and Settings says why. A relay that serves no model list to check against keeps the key you typed. While a key is checked, Settings says so instead of showing an old refusal.
- A key that comes from an environment variable is shown with the variable's name, instead of offering Remove key.
- A harness that is missing says it is not installed. Muse Code on Sign in says it cannot be known signed in until a turn runs. The words about Antigravity's install and sign-in, and about a Codex account Trebell could not read, are plain, without program or protocol names.
- Trebell Native on Meta offers Thinking Max for Muse Spark 1.3 Contributor.

## The composer

- **Each conversation keeps its own draft and attached files.** A draft typed in one thread never shows or sends in another, and New task keeps its own. A thread that a harness switch closes keeps its draft and files too.
- **Muse Code's own commands are in the / menu from the start**, its folder's own skills among them, with short descriptions, and a command you pick runs as Muse's command. A message steered into a running Muse Code turn that starts with one of Muse's commands is not sent, and the draft stays to go as a message of its own.
- The mic shows it is on from the press, a second press stops dictation, and Trebell says why dictation stopped or never started.
- The composer's context reading follows the turn's last request where the model's context window is not known, instead of every request of the turn added up.
- The Cite chip shows the length of the text you cited.
- The @ menu opens for an @ right after an opening bracket or quote, and a file picked from it keeps the punctuation you typed after it.
- The new task's welcome fits the room the terminal drawer leaves, so the composer never covers its title.

## Conversations

- A reply keeps its single line breaks as written.
- A wide table in a reply keeps each cell's words and numbers whole and scrolls sideways.
- A new thread takes its title from its first message as it is sent, Codex threads included.
- The Usage page names turns that ran on this computer Local machine.

## Open source

## Install and update

- Windows x64: download and run `Trebell-Code-Setup-2.1.5.exe` from the releases repository, https://github.com/tanishqbaweja/trebellcode-releases.
- If you have 2.0.0, 2.0.1, 2.1.0, 2.1.1, 2.1.2, 2.1.3 or 2.1.4, the in-app updater offers 2.1.5; it downloads and installs only when you choose to.
- The installer is not signed, so Windows SmartScreen may ask you to confirm it before it runs (More info, then Run anyway).

# Trebell Code 2.1.6

Version 2.1.6 is an update to 2.1.5. Trebell Native now has a Speed option on Anthropic, as on OpenAI: keep it at Standard, or pick Fast for the models that offer a faster tier.

## Trebell Native

- **Speed, Standard or Fast, on Anthropic and OpenAI.** The composer shows one Speed option for every Native model that has a faster tier.
  - On Anthropic, Fast turns on Anthropic's fast mode for Claude Opus 5.5, Claude Opus 5 and Claude Opus 4.8: the same model writes up to 2.5 times faster and costs about twice as much per token.
  - On OpenAI, Fast uses OpenAI's priority processing for the models that offer it, as before: the same model answers faster and costs more per token.
  - The option's tooltip says what Fast does and that it costs more. Standard is the default, and with Standard Native sends exactly what it sent before.
- When Anthropic's fast mode is busy, Native waits for the time Anthropic gives and tries again at fast speed, instead of switching to standard speed without telling you.
- Each turn records which speed Anthropic actually used.
- Some of this is in the code that Trebell's benchmark runs share with the app, so the Native you download is still the Native the benchmarks run. A benchmark run that does not pick Fast sends the same requests as before.

## Install and update

- Windows x64: download and run `Trebell-Code-Setup-2.1.6.exe` from the releases repository, https://github.com/tanishqbaweja/trebellcode-releases.
- If you have 2.0.0, 2.0.1, 2.1.0, 2.1.1, 2.1.2, 2.1.3, 2.1.4 or 2.1.5, the in-app updater offers 2.1.6; it downloads and installs only when you choose to.
- The installer is not signed, so Windows SmartScreen may ask you to confirm it before it runs (More info, then Run anyway).

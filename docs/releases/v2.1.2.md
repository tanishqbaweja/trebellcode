# Trebell Code 2.1.2

Version 2.1.2 is a small update to 2.1.1. Trebell Native on the Meta Model API no longer ends a turn with an error when it needs one particular tool called. The runtime log in Settings, Diagnostics reads as plain text, two messages in the interface read as plain sentences, and Windows now names Trebell as the company in the app's and the installer's details.

## Trebell Native

- **Turns on the Meta Model API no longer fail when Native needs one particular tool called.** At some steps Native asks the model to call a given tool, for example when you name a tool to call. Meta's API takes only automatic tool choice and refused those requests, which ended the turn with an error. Native now offers Meta just that tool with automatic choice, and the turn goes on.
- Native's requests to OpenAI, xAI and the other providers are unchanged. Native in the app and in Trebell's benchmark runs still read one shared configuration, so the Native you download is the Native the benchmarks run.

## Interface

- **The Diagnostics runtime log reads as plain text.** The colour, cursor and other control codes the Codex app-server writes for a terminal no longer show up in Settings, Diagnostics as stray characters around words such as ERROR, including codes that a WSL or SSH environment's connection delivers in two pieces. An accented letter or other special character that arrives in two pieces now shows whole instead of as stray characters.
- The Projects page's hint for saved actions and the composer's message when no models are available read as plain sentences.

## Install and update

- **Windows names Trebell as the company.** The app's file details named the company behind the framework the app is built on, and the installer's named none. Both now name Trebell, and so do the copyright line in those details and the publisher that Windows lists for Trebell Code under installed apps.
- Windows x64: download and run `Trebell-Code-Setup-2.1.2.exe` from the releases repository, https://github.com/tanishqbaweja/trebellcode-releases.
- If you have 2.0.0, 2.0.1, 2.1.0 or 2.1.1, the in-app updater offers 2.1.2; it downloads and installs only when you choose to.
- The installer is not signed, so Windows SmartScreen may ask you to confirm it before it runs (More info, then Run anyway).

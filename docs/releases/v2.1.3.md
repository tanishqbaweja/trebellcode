# Trebell Code 2.1.3

Version 2.1.3 is an update to 2.1.2. A project's `trebell.json` uses new names for its settings, so a file written for 2.1.1 or 2.1.2 needs its keys renamed (Projects, below, says how). A message can be longer, attached documents are read further and more fully, approval cards from Grok Build, Antigravity and Cursor show each harness's own choices, background work in Muse Code and Claude Code can run for longer, and many labels and messages across the app read more plainly.

## Projects

- **`trebell.json` uses new names for its settings.** A project's shared file now lists `actions`, each with a `label` and a `run` command, and optionally a `preview` address, `openPreview` (true to open the preview when the action starts) and `onNewWorktree` (`wait` to run the action when Trebell makes a worktree and wait for it, `start` to run it then and go on). `workspace` sets where a new thread works (`worktree` or `current`), and `submodules` how deep a new worktree's submodules go (`all`, `first-level` or `none`).
- **A `trebell.json` written for 2.1.1 or 2.1.2 shows no actions or defaults until its keys are renamed.** Such a file uses `scripts`, `defaultThreadEnvMode` and `worktreeSubmodules`, and the Projects page says it found the file but reads nothing in it. To bring an older file over:
  - `scripts` becomes `actions`, and in each action `name` becomes `label`, `command` becomes `run` and `previewUrl` becomes `preview`.
  - `autoOpenPreview`: any value 2.1.2 read as on (true, or any other value but false, 0, an empty string or null) becomes `"openPreview": true`; otherwise leave `openPreview` out.
  - `runOnWorktreeCreate`: true with `async` false becomes `"onNewWorktree": "wait"`. Any other value 2.1.2 read as on (true with `async` missing or anything but false, or any other value but false, 0, an empty string or null) becomes `"start"`. False (or 0, an empty string, null) or no value means leaving `onNewWorktree` out, since 2.1.2 did not run that action on a new worktree. `async` is no longer read.
  - `defaultThreadEnvMode` becomes `workspace`: `"worktree"` stays `"worktree"` and `"local"` becomes `"current"`. 2.1.2 read no other value, so for any other leave `workspace` out.
  - `worktreeSubmodules` becomes `submodules`: `"recursive"` becomes `"all"`, `"top-level"` becomes `"first-level"` and `"none"` stays `"none"`. 2.1.2 read no other value, so for any other leave `submodules` out.
- The Projects page heads a project's actions Saved actions, and an action's preview switch reads Show the preview each time this action runs. Its hint for the file reads trebell.json found, with Use its workspace and Use its submodules.

## Composer and threads

- **A message can be up to 200,000 characters.** The composer took 120,000. Codex itself takes up to 1,048,576.
- **A new thread's title holds up to 80 characters of its first message**, where it held 50. Threads titled before keep their titles.
- Cite takes up to 6,000 characters of selected assistant text, where it took 8,000. Over that, its button reads Too long.
- A harness's reasoning is labelled Reasoning while it streams and when it is done, with Show reasoning and Hide reasoning on its toggle, where it read Thinking and Thought.
- The activity row for a search names the text searched for first, then the folder, so a search for a word in `*.js` files reads Looked for and the word. A search by file pattern alone reads Listed and the pattern, such as Listed **/*.ts in components.
- In a Codex thread, the /goal command is described as giving Codex an objective to pursue across turns, which you can pause, resume or clear.

## Approvals and questions

- **Approval cards show the harness's own choices.** For Grok Build, Antigravity and Cursor, and for OpenCode on a WSL or SSH environment, each button carries the name the harness gives its option, in the harness's order. An option that comes without a name reads Allow this time, Allow and remember or Don't allow.
- **The card's last button reads Cancel this request.** It answers that one request as cancelled, and the turn goes on; the composer's Stop ends the turn.
- An Antigravity security warning shows with the choice it comes with, cut to about four lines.
- An Antigravity question with no title reads "Antigravity asks you to pick one of these.", a Cursor question with no words says that Cursor sent it without any, and a Cursor plan that came without its text shows the plan's overview, or says that Cursor sent none of its text.

## Harnesses

- **Background work keeps Muse Code's and Claude Code's process for up to eight hours**, where 2.1.2 kept it for four: Muse's work from its last word, Claude's from the end of the turn that started it. When the hold ends the process is closed, and any of that work still running stops with it.
- **Claude Code has two minutes to connect a thread's MCP servers**, where it had 90 seconds, and says so when it runs out.
- **A new Codex thread starts on the model Codex marks as its default**, as Codex itself picks one. 2.1.2 put a few models it named ahead of Codex's choice. When Codex marks none, the thread starts on the first model Codex lists.
- **A Codex account with its own sign-in home keeps its own memories.** That home also keeps its own cloud settings cache and app-server state, where 2.1.2 linked these to your main Codex home. Trebell takes those links away, and Codex starts these afresh in that account's home. Its sessions, config, skills, plugins and worktrees are still shared.
- Codex's ChatGPT plans show under the names Codex's own /status gives them, such as Enterprise, Edu Plus and Academic Researchers.
- Cursor's None and Minimal reasoning levels show in the composer when Cursor offers them for a model. When Cursor's account check gives words that are not an email address, Trebell counts Cursor as signed out.
- Grok Build's /auto command is no longer offered in the composer, as /always-approve already was not: Trebell starts Grok Build at the thread's access level and answers its permission requests itself.
- **Antigravity sends images as Google's models take them.** PNG, JPEG and WebP images go as images of up to 7 MB each, and a BMP is named by its saved path instead. A message that cannot carry an image is not sent, and Trebell says which image and why: it is over 7 MB, or it does not fit beside the other attachments, so it needs a message of its own. A text file of up to 7 MB goes with the message, where 1 MB was the most, and an audio file is no longer held to 20 MB.
- **Antigravity's runtime install keeps 512 MB free on its drive**, where it kept 256 MB, and says so when the drive has less.
- When Google says an account's plan does not include Antigravity, Trebell says so and suggests an account whose plan includes it or a Google Gemini API key.
- OpenCode Go's usage rows read OpenCode Go 5-hour limit, OpenCode Go weekly limit and OpenCode Go monthly limit.
- A row about a request being sent again says who sends it, when and which try it is, for example "429 Too Many Requests. Muse Code sends the request again in 2 s, as try 2 of 3."
- When a harness fails and Trebell quotes the end of its log, the quote hides more kinds of keys and tokens.
- Messages from Claude Code, Muse Code, OpenCode, Grok Build and Codex read more plainly when a turn ends early, a usage allowance runs out or a sign-in cannot be checked, for example "Claude Code has used up its weekly allowance."

## Documents you attach

- **Larger documents are read.** A Word, OpenDocument, RTF, EPUB, Excel or PowerPoint file of up to 50 MB, or a notebook of up to 20 MB, is read into text, up to 2,000,000 characters. 2.1.2 read files of up to 16 MB, and up to 1,000,000 characters.
- Each sheet, slide, e-book section and notebook cell is headed with its place and the count, such as Sheet 2 of 3: Rates or Slide 1 of 4. A hidden sheet says so, and speaker notes and a cell's output are marked.
- In Excel files, a number in a date, time or percent format reads as the date, time or percentage, TRUE and FALSE read as such, and a formula with no saved value shows the formula.
- Word files leave out deleted text and field codes, OpenDocument files leave out comments and tracked deletions, and an e-book's title no longer runs into its first heading. RTF files in double-byte code pages, such as Japanese, are read.
- When a document holds more than Trebell reads, its text ends with "[The document goes on, but Trebell Code read only this much of it.]"

## Source control

- The Source Control panel's pull request words read more plainly: Pull requests on this thread, On threads, Reading pull requests and Pull requests are not listed, and a pull request with nothing to show says This pull request has no checks, Nobody has commented or Nobody has reviewed it. The merge question says how many checks have not finished.
- The box for feedback on a pull request is headed New comment or New review, and a review's fields are labelled Review comment and Review type.
- When a push is refused because the branch on the remote holds commits this branch lacks, Trebell says first: "The branch on the remote holds commits that are not in this branch yet. Bring them in first, then push."
- Rebasing a GitHub stack checks every open pull request in it before it fetches or pushes anything.
- The instructions Trebell gives for a commit message or pull request text are reworded for each Git text style. With The repository's own style, they ask for the habits the repository's commit history and guidance files show, and for a short, plain subject when there are none.
- Messages from Forgejo and Gitea, Bitbucket, GitLab and Azure DevOps read more plainly and say what to do, for example which fj or tea login to add.
- Going back in a conversation with its files says plainly when the files cannot go back, for example when another thread also works in the same folder.

## Settings and the rest of the interface

- Settings labels read more plainly: Settings below are for, Submodules in new worktrees (All levels, First level or None), Remove worktrees automatically, Messages sent during a turn, Panel motion, Light up the window on capture, Add a model by ID, Claude Code's Compaction threshold, Codex's Sign-in home for this account, and the Git text style The repository's own style.
- Shortcut names read Toggle sidebar, Search this thread, Copy pull request link or thread ID and Copy pull request number. The thread menu offers Copy ID, and the search palette says Looking through messages while it searches.
- The terminal says when older output is gone, the context inspector lists Extra context sent to Codex, the Environments page says "No remote environment is saved. Agents run on this computer.", and the Usage page says when the reset credit is spent or could not be spent.
- **Open in tries Visual Studio Code first.** With no editor chosen, it starts the first editor it finds on this machine, and now looks for Visual Studio Code and its builds before the others, where it looked for Cursor first. It can also start Sublime Text, finds the Antigravity editor by its `antigravity` command too, and names Visual Studio Code Insiders in full.
- When SnapShots captures a window, the cue over it is one box with the app's accent ring that fades out, and it no longer grows.
- Commands on a WSL or SSH environment find Node tools installed with Volta, mise, asdf, nodenv and fnm before those of nvm, and follow each tool's own folder settings, such as `VOLTA_HOME` and `NVM_DIR`.
- An environment's theme folder takes theme files of up to 96 KB each, so larger VS Code color themes show, with up to 24 files and 512 KB in all. 2.1.2 took up to 32 files of up to 32 KB each, 192 KB in all.

## Trebell Native

- Trebell Native hides secrets in what its model reads exactly as 2.1.2 does. A push the remote refuses reads to it in the new words under Source control. Native in the app and in Trebell's benchmark runs still read one shared configuration, so the Native you download is the Native the benchmarks run.

## Install and update

- Windows x64: download and run `Trebell-Code-Setup-2.1.3.exe` from the releases repository, https://github.com/tanishqbaweja/trebellcode-releases.
- If you have 2.0.0, 2.0.1, 2.1.0, 2.1.1 or 2.1.2, the in-app updater offers 2.1.3; it downloads and installs only when you choose to.
- The installer is not signed, so Windows SmartScreen may ask you to confirm it before it runs (More info, then Run anyway).
- If a project has a `trebell.json` written for 2.1.1 or 2.1.2, rename its keys as Projects, above, says, so its actions and defaults show again.
- The third-party notices that come with Trebell Code name only the open-source packages it ships.

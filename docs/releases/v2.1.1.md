# Trebell Code 2.1.1

Version 2.1.1 is a small update to 2.1.0. Trebell Native on the Meta Model API now streams the requests of each turn, so a long answer no longer fails after five minutes. A project's shared settings file is now `trebell.json`, Bitbucket credentials come only from Trebell's own variables, and many messages from the harnesses and the interface read more plainly.

## Trebell Native

- **Long answers on the Meta Model API.** Native now streams the requests of each turn to the Meta Model API instead of waiting for the whole answer in one reply, which was cut off after five minutes. A long answer, such as long reasoning or a long tool call that writes a big file, now finishes instead of failing. The reply still shows once it is complete, and its usage is recorded as before. A commit message or pull request text that Native writes for the Git panel is still sent as one request.
- The connection stays open through long silences while the model thinks or writes, past the idle limits of routers and firewalls. A stream that sends nothing for 30 minutes, breaks or ends early is sent again, as a request that timed out is. Once Meta has sent the complete answer, Native keeps it even if the connection then drops or stays open, so a finished answer is never paid for twice.
- When Meta reports a rate limit, an overload or an unavailable service in the middle of an answer, Native waits as long as Meta asks, up to a minute, or 15 seconds for a rate limit and 60 seconds otherwise, before it tries again. A request that fails is cancelled cleanly, closing its connection at once.
- Native's requests to OpenAI, xAI and the other providers are unchanged. Native in the app and in Trebell's benchmark runs still read one shared configuration, so the Native you download is the Native the benchmarks run.

## Projects and source control

- **A project's shared settings file is `trebell.json`.** Trebell reads a project's shared actions and workspace defaults from `trebell.json` at the project's root, and no longer from `t3.json`. A project that keeps them in `t3.json` shows none on the Projects page until the file is renamed to `trebell.json`.
- **Bitbucket credentials come only from Trebell's own variables.** Trebell reads them from `TREBELL_BITBUCKET_ACCESS_TOKEN`, or from `TREBELL_BITBUCKET_EMAIL` with `TREBELL_BITBUCKET_API_TOKEN`, and no longer from the `T3CODE_BITBUCKET_ACCESS_TOKEN`, `T3CODE_BITBUCKET_EMAIL` and `T3CODE_BITBUCKET_API_TOKEN` variables. Set the Trebell names to keep Bitbucket working.
- A stack merge or rebase that fails now says Merging the stack failed or Rebasing the stack failed, with the reason, and the Custom Git instructions box shows a shorter example.

## Harnesses

Several harness messages now say plainly what happened and what to do next.

- Claude Code and the Codex CLI say they are signed out, with the command that signs them in again (`claude auth login`, `codex login`).
- **Claude Code.** It says in plain words why it stopped a turn, for example that the thread no longer fits the model's context window (run /compact, or start a new thread), that the API kept failing or that it could not read an image in the thread. When the Claude API is overloaded or its rate limit was hit, the message says so and asks you to send your message again. An image Claude Code cannot take is refused with the kinds it takes: PNG, JPEG, GIF and WebP.
- **Grok Build.** Its usage limit says to send the message again once it resets, as Claude Code's and Muse Code's do. Its approval choice reads Allow edits for the rest of this session, a plan mode it leaves without a plan says Grok Build left plan mode without writing a plan, and an error it gives no detail for reads Grok Build reported an error and ended the turn.
- **OpenCode.** Its status says that it runs with its upstream providers connected and lists their models, or that no upstream provider is connected through it.
- **Antigravity.** It says when a model you picked is not offered to your Google account.
- A few other error messages are reworded too, with the same meaning.

## Interface

- Search rows in a turn now read Looked for slugify in src, Listed `*.js` or Looked in src, instead of Searched slugify in src, Searched files `*.js` or Searched in src.
- The wrap button in the Changes tab is labelled, and its tooltip reads, Wrap diff lines or Stop wrapping diff lines.
- A Codex thread without a goal now says This thread has no goal.

## Other

- In the text Trebell extracts from an attached spreadsheet, a number shown as a date, a percentage or in a format of the workbook's own is followed by that format in plainer words, and an OpenDocument percentage says it is shown as a percentage.
- The third-party notices that ship with the app (`THIRD_PARTY_NOTICES.md`) now name every part of Trebell Code written from another project's MIT-licensed source, with that project's copyright line and license text. Earlier releases carried an incomplete notice.

## Install and update

- Windows x64: download and run `Trebell-Code-Setup-2.1.1.exe` from the releases repository, https://github.com/tanishqbaweja/trebellcode-releases.
- If you have 2.0.0, 2.0.1 or 2.1.0, the in-app updater offers 2.1.1; it downloads and installs only when you choose to.
- The installer is not signed, so Windows SmartScreen may ask you to confirm it before it runs (More info, then Run anyway).
